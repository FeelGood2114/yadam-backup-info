처리하는 정보와 목적

계정 소유자가 선택한 제작 자료와 운영 데이터베이스의 사본을 백업·복원하는 목적으로 처리합니다. 자료에는 대본, 인물·목소리 배정, 작업 상태·사용 기록, 이미지, 음성, 영상, 자막 등이 포함될 수 있습니다. 실제 백업 대상은 로컬 도구에서 선택한 범위에 따릅니다.

Google OAuth 인증정보는 사용자가 허용한 Google Drive 파일에 접근하고 인증을 갱신하는 데 사용합니다. 현재 로컬 인증 파일은 Windows의 사용자 접근 권한으로 보호합니다. 이 설명은 별도 파일 암호화나 모든 공격에 대한 보호를 보장한다는 뜻이 아닙니다.

저장 위치와 전송

백업 자료는 계정 소유자의 컴퓨터와 계정 소유자가 지정한 Google Drive에 저장됩니다. 이 도구 운영자를 위한 별도의 중계 서버에 자료를 보관하지 않습니다. Google Drive 저장·전송에는 Google 서비스가 사용되며 해당 서비스의 정책도 적용됩니다. 계정 소유자가 별도로 선택한 공유 설정의 영향은 별개입니다.

이 도구는 Google에서 받은 자료를 광고·판매 또는 범용 AI 모델 학습 목적으로 제공하도록 설계되지 않았습니다. Google API Services User Data Policy와 그 Limited Use 요구사항을 준수하는 범위에서 Google API 정보를 사용·전송합니다.

보관과 삭제

백업 파일은 계정 소유자가 관리합니다. 보관 주기와 삭제는 실제로 설정된 백업 정책에 따르며 이 안내문만으로 자동 삭제가 실행되지는 않습니다. 현재 원본에서 삭제된 파일을 클라우드에서 즉시 삭제하는 동작은 설정하지 않았습니다.

사용자는 Google 계정의 연결된 앱 관리에서 접근 권한을 철회할 수 있습니다. 권한 철회만으로 이미 저장된 백업 파일이 삭제되지는 않습니다. 파일 삭제가 필요하면 Google Drive에서 해당 백업 파일과 휴지통을 관리해야 합니다. 로컬 인증 파일과 백업본도 별도로 관리해야 합니다.

안내 사이트와 문의

이 정적 안내 페이지에는 자체 로그인·추적·광고 기능을 넣지 않습니다. 사이트 호스팅 및 문의 플랫폼인 GitHub가 자체적으로 처리하는 정보에는 GitHub의 정책이 적용됩니다. 문의는 안내 페이지 저장소의 문의 게시판를 이용하며 파일 내용·인증정보·개인정보를 공개 문의에 포함하지 마세요.

이 문서는 기능·데이터 취급 방식 변경 시 갱신합니다.
